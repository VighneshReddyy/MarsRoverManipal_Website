# Mars Rover Manipal website

The current website is a Next.js application. Install dependencies with `npm install`, run it locally with `npm run dev`, and create a production build with `npm run build`.

## Folder guide

- `app/` contains website pages and styles.
- `components/` and `hooks/` contain reusable interface code.
- `lib/` contains website data and utilities, including the cached team data.
- `public/` contains assets served by the website.
- `scripts/` contains data and asset maintenance scripts; run them from the project root.
- `archive/` holds older site files and original board photographs kept for reference.
- `mrm2021/` is the separate older project.

`node_modules/` and `.next/` are generated locally and are not source files.
